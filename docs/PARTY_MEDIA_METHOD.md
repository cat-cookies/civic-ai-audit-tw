# 政黨與媒體分析方法

## 政黨資料層級

1. 黨綱、黨章、全代會決議及政策綱領
2. 中央黨部正式新聞稿
3. 立法院黨團正式提案與協商文件
4. 中央黨部官方 Facebook、Instagram、Threads
5. 黨主席
6. 個別公職與地方黨部

不同層級不得自動合併。只有中央黨部或正式黨團資料，才可作為全黨主張的高權重證據。

## 意識形態萃取

保留能區辨政黨的國家認同、憲政民主、經濟社會、兩岸外交、能源環境及治理命題。「為民服務」「促進福祉」等跨黨共通口號，除非附有制度工具，否則降低權重。

## 媒體分析

單篇層級：各黨批評、稱讚、描述性語句、官方論述接近度、消息來源平衡、回應機會、標題內文一致性。

媒體層級：至少30篇、3個議題、4週；分開新聞、評論、政論及轉載；衡量報導量的選擇偏誤；人工雙人標註與信賴區間。

政府持股、政府預算或政府任命只能標示結構性依賴風險，不能直接推論內容偏向執政者。
