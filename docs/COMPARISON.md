# 兩個 ZIP 比較與取捨

| 項目 | 原觀測站 | 多語學術助理 | 新版處理 |
|---|---|---|---|
| 公開網站 | 已有八分頁與靜態資料 | 非主要用途 | 保留並重構 |
| 搜尋 | 分頁篩選為主 | 有語言／任務路由思想 | 新增統一模糊搜尋與法條精確路由 |
| 證據治理 | 有來源與人工審核 | 有主張—證據、反方審查概念 | 自行重寫可驗證矩陣 |
| 多模型 | 固定候選與五／六次描述不一致 | 有多角色思路 | 明定最多六次、風險自適應 |
| 授權 | MIT | 混合 MIT、CC BY-NC、授權不明 | 不整包合併；只獨立實作通用方法 |
| 部署 | GitHub Pages | 不適用 | Pages只公開白名單；處理與審核分離 |
| 政黨分析 | 矛盾檢查 | 不適用 | 改為一致性與變動分析 |
