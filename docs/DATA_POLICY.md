# 資料分級

| 資料類型 | 外部免費模型 | 受控契約模型 | 本機模型 |
|---|---:|---:|---:|
| 公開官方資料 | 可，但須白名單與來源範圍限制 | 可 | 可 |
| 公開非官方資料 | 個案審核 | 可 | 可 |
| 未公開政策或機關資料 | 禁止 | 依契約、權限與目的核准 | 受控環境 |
| 個人資料 | 原則禁止 | 去識別化後個案核准 | 受控環境 |
| 醫療、司法、陳情個案 | 禁止 | 原則禁止 | 嚴格權限與日誌 |
| 律師、研究或機關內部文件 | 禁止 | 依保密義務與契約 | 受控環境 |

`data_policy.py` 在模型呼叫前執行，而不是等到發布前才阻擋。偵測只是最低限度防線，不能取代資料所有人、目的限制、最小化、去識別化與權限管理。
