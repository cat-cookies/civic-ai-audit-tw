# 架構

## 搜尋先行

查詢路由器先辨識完整法規名稱與條次；其餘以本地索引進行模糊排序。初始檢索不依賴生成式模型，避免模型改寫或猜測使用者查詢。

## 證據處理

原始位元組 → 雜湊與擷取中繼資料 → 文件版本／效力 → 主張拆分 → 逐字引文驗證 → 規則檢查 → 模型支持與反駁 → 來源衝突 → 人工審核 → 白名單發布。

## 法律與政策分流

政策形成回答問題建構、目標、替代方案、成本、分配與執行；法律形成回答法源、權限、法律保留、比例原則、條文構成要件、程序保障、救濟與法體系一致性。網站不得把政策偏好冒充法律義務，也不得把形式合法等同政策有效。

## 部署邊界

公開站不含 `data/raw/`、`data/private/`、`review/`、模型設定或任何金鑰。模型輸出預設不公開。
