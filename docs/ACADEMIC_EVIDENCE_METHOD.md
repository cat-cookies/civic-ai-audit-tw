# 學說、期刊文獻與研究推論方法

## 一、定位

本站的學術模組用於協助使用者選擇可解釋問題的理論、辨識可檢驗命題、連結適合的研究方法，以及取得代表性期刊文獻。它不是自動文獻回顧器，也不會因為某一理論或論文被檢索到，就推定該理論已能解釋具體案件。

## 二、理論資料模型

每項理論至少包括：

- 理論名稱與學科領域
- 核心主張
- 作用機制
- 診斷問題
- 適用情境
- 不適用或容易誤用之處
- 可檢驗命題
- 建議研究方法
- 代表性文獻識別碼

理論只在問題意圖、機制與可檢驗問題相符時列為候選。單一關鍵字命中不足以支持理論選用。

## 三、文獻來源層次

1. **內建代表性文獻**：經人工選定的理論或方法起點，附 DOI 與完整引用資訊。
2. **Crossref 擴充結果**：用於取得 DOI、作者、期刊、出版年等書目中繼資料。
3. **Europe PMC 擴充結果**：用於生命科學與醫療相關出版品之書目及摘要資訊。
4. **全文與附錄**：仍須由研究者依法取得並閱讀，本站不以中繼資料替代全文判讀。

## 四、不得自動推論的事項

- DOI 存在不等於研究品質良好。
- 同儕審查不等於沒有偏誤。
- 引用次數高不等於適用於目前問題。
- 單篇論文不等於完整證據體系。
- 國外制度有效不等於可直接移植至中華民國。
- 理論符合部分現象不等於排除其他解釋。

## 五、建議的文獻判讀欄位

- 研究問題與理論假設
- 研究設計與識別策略
- 樣本、資料來源及時間範圍
- 主要變項與操作化
- 對照組、反事實或比較基準
- 主要結果與效果大小
- 不確定性、敏感度與穩健性檢查
- 內部效度、外部效度與可移植性
- 利益衝突、資助來源與資料可得性
- 對目前政策或法律問題可支持及不可支持之事項

## 六、跨國比較

跨國比較預設採功能比較：先確認各制度欲解決的問題、權限配置、程序保障、財政與行政能力，再比較法律文字。比較結果至少區分：

- 可直接比較的功能
- 法制體系差異
- 組織與執行條件差異
- 文化與歷史脈絡
- 可移植元素
- 不宜移植元素

## 七、推論帳本

每項較強結論應記錄：

- 結論或推論
- 直接證據
- 推論前提
- 反方證據與替代解釋
- 來源衝突
- 可檢驗預測
- 何種新資料會推翻或修正結論
- 信心水準及其理由

## 八、文獻引用輸出

前台支援 APA、RIS 與 BibTeX。輸出前仍應核對作者順序、年份、篇名、期刊、卷期、頁碼及 DOI；API 回傳中繼資料可能不完整或後續更正。
