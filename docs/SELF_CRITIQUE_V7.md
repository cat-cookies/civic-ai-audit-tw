# v7.0.0 工程、方法與法律自我批判

## 一、前版核心失敗

1. 各分頁各自起題，缺乏同一研究問題的累積脈絡。
2. 本地索引容易被誤認為完整搜尋；固定理論清單也可能反客為主。
3. 單一證據金字塔混淆效果、危害、診斷、預後、政策因果、實施、質性與法學問題。
4. AI查詢擴張若未顯示與確認，可能暗中改變研究範圍。
5. 「網絡圖」若未標示關係狀態，容易讓概念相關被誤讀為因果。
6. 免責文字無法取代合理查證、個資控制、著作權、回應權與更正機制。

## 二、v7修正策略

- 建立單一研究工作階段，所有頁面共用提示詞、來源、文獻、圖與分析。
- 廣泛問題先以規則式 Grill-me 追問；AI追問是選配。
- 線上公開網域與期刊API優先，本地資料不再作主要答案。
- AI擴張詞逐項顯示風險，須由使用者勾選確認。
- 文獻依入門、核心、進階排序，但明示閱讀順序不等於品質等級。
- 證據依問題類型路由；GRADE評估特定結果的整體證據體。
- 概念網絡的每條邊分為有支持、部分支持或假設；不是統計網絡統合分析。
- 外國制度一律增加中華民國適用性、移植條件與不可移植部分。
- 不設檔案上傳；只解析通過網域、robots、SSRF、格式與大小檢查的公開URL。
- 非中國大陸模型同時以供應商前綴與模型名稱片段阻擋；額度用盡即停止。

## 三、仍未解決的風險

1. Crossref、Europe PMC與OpenAlex多為書目或摘要，不能證明已閱讀全文。
2. APA自動格式可能缺作者、日期、版本或機構名稱，公開前仍應校正。
3. 搜尋API的索引、排序與地區覆蓋會造成不可見的選擇偏誤。
4. OCR可能誤讀表格、腳註、公式與掃描法條，因此預設關閉。
5. DOCX、PPTX與PDF解析只抽取可讀文字，圖表及版面關係可能遺失。
6. 免費模型的可用性、額度、資料使用政策與版本會變動。
7. 規則式問題分類與理論推薦仍可能錯分，必須讓使用者改選。
8. 本次已完成語法、單元、資料契約、建置與ZIP重解壓測試；正式瀏覽器、外部API及部署環境仍須上線後驗證。

## 四、不得誇大的結論

- 通過測試只代表已檢查的程式路徑可運作，不代表內容正確或法律安全。
- 有APA格式不代表來源可靠；有高排名期刊不代表可直接適用中華民國。
- 多模型一致不代表事實成立。
- 政府資金、政黨語彙接近度或單篇新聞語氣都不能單獨證明政治控制或媒體偏向。
- 免責聲明不能排除依法不得排除的責任，也不能取代合理查證。
