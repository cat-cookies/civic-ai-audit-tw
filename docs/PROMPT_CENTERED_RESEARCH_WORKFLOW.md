# 提示詞中心的社會議題研究流程

1. 問題界定：偵測過廣提示，追問對象、機制、結果、時間、法域與使用目的。
2. 合法搜尋：依資料領域、法域及使用者明確指定網域串接公開API與受控搜尋。
3. 概念網絡：以行動者、制度、法規、機制、結果、價值、證據、反方及改革工具呈現社會結構。
4. 證據評讀：依效果、危害、診斷、預後、政策因果、實施、質性或法學問題選擇研究設計；另以GRADE評估證據體確定性。
5. 學說與期刊：只依提示搜尋，分為入門、核心與進階閱讀，並由選取文獻整理研究缺口及可行方向。
6. 跨國比較：比較功能與機制，逐項檢查政體、法制、語言、政黨競爭、資料可得性、歷史文化及執行能力。
7. 改革與修法：比較維持現狀、行政、預算、資訊揭露及修法，產出三種強度版本與APA參考資料。
8. 反思：要求最強反證、替代解釋、遺漏群體、外溢效果及會改變結論的新資料。

所有AI查詢擴張須由使用者主動啟用並顯示展開詞；系統不得把同一議題中的不同概念當成近義詞。
